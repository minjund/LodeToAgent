# 스케치 001: Intent-first Control Room

## 디자인 질문

현재 기능과 에이전트 움직임을 잃지 않으면서, 첫 화면이 사용자에게 한 가지 명확한 질문만 건네려면 무엇을 중심에 두어야 하는가?

## 보는 방법

`.planning/sketches/001-intent-first-control-room/index.html`을 브라우저에서 연다.

## 변형

- **A: 판단 우선** — 지금 사용자가 결정해야 하는 한 가지를 크게 보여주고, 실행 중인 일은 조용한 오른쪽 레일로 남긴다.
- **B: 살아있는 위임** — 메인 에이전트와 서브에이전트의 관계를 흐르는 선과 역할 카드로 보여준다.
- **C: 한 줄의 시간** — 화면을 여러 영역으로 나누지 않고 과거·현재·다음 순서로 작업을 읽게 한다.

## 무엇을 찾아봐야 할 것

- 처음 3초 안에 “내가 지금 해야 할 일”을 알 수 있는가?
- 서브에이전트가 많아져도 관계를 이해할 수 있는가?
- 애니메이션이 생동감을 주면서도 집중을 방해하지 않는가?
- 상세 정보가 필요할 때만 자연스럽게 나타나는가?

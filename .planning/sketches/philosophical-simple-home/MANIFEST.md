# Philosophical Simple Home

## Intent

The dashboard should not describe everything. It should make the user's next judgment clear.

## Shared principles

1. One screen, one question.
2. Decisions are louder than status.
3. Running work stays visible but quiet.
4. Details appear only after intent.
5. Empty space is operational clarity, not unused capacity.

## 역할 기반 탭

### 확인 요청

- 사용자의 승인·선택·개입이 필요한 작업만 보여준다.
- 가장 중요한 요청 하나만 펼쳐 판단 맥락과 행동을 제공한다.
- 현재 실행 중인 작업은 우측의 조용한 보조 정보로 남긴다.

### 실시간 흐름

- 메인 에이전트, 서브에이전트, 결과 정리의 관계를 중심에 둔다.
- 세션 선택은 왼쪽, 선택한 에이전트의 역할과 개입 행동은 오른쪽에 둔다.
- “누가 무엇을 하고 어디까지 왔는가”에 답한다.

### 전체 작업

- 진행·확인·완료 작업을 하나의 목록에서 찾는다.
- 각 행은 상태, 작업명, 현재 문장, 경과 시간, 행동만 가진다.
- 검색과 빠른 조회가 필요한 숙련 사용자에게 적합하다.

## Deliberately removed from the first view

- Provider quota cards
- Beginner guide
- App connection card
- Multiple project filters
- Expand/collapse controls
- Terminal and tmux shortcuts
- Global statistics cards
- Decorative status labels that repeat the same state

These remain available in settings, secondary navigation, or contextual detail.

# 현재 기능 → 인과선 워크벤치 배치표

| 기능 영역 | 현재 구현 기능 | 새 위치 |
|---|---|---|
| 홈·실시간 흐름 | 여러 세션, 프로젝트, 메인·서브에이전트, PowerShell·백그라운드 실행, 완료 증거, 검색·정렬·필터, 모두 열기·닫기 | 세션별 병렬 인과선. 주의할 세션 하나는 펼치고 나머지는 축약 |
| 확인할 일 | 진행 차단, 선택적 제안, 실패·지연·일시정지 위험, 승인·거절·답장·재할당 | 좌측 `확인` 화면, 홈의 단일 주황 신호 |
| 전체 작업·기록 | 최근 24시간 작업, 제공사 필터, 검색, 사용량·컨텍스트 정렬, 더 보기, 완료 기록 | 좌측 `전체 작업` 화면 |
| 작업 상세 | 요약, 시간순 대화, 전달 상태, 과정, 사용량, 증거, 직접 메시지 | 노드 선택 시 열리는 컨텍스트 도크 |
| 실행 제어 | 중단, 일시정지, 재개, 재시도, 재할당, 새 세션 | 상세 도크의 상태별 행동 |
| 새 AI 작업 | 요청, 빠른 예시, AI 선택, 폴더, 쓰기 허용, 모델 | 전역 `새 작업` 모달 |
| 예약·실행 단계 | 예약 목록, 활성·일시정지, 반복 실행 단계, 현재 단계, 작업 열기 | 좌측 `예약` 화면 |
| AI 세션 터미널 | 세션 목록, Windows·WSL 생성, 이전 대화, 실시간 출력, 명령 입력, 중단·정리·재시작·재연결·종료, 글자 크기·집중 보기 | 좌측 `터미널` 전체 작업면; 상세 도크에서 문맥을 이어 열기 |
| tmux 관리 | 세션→창→pane→AI 관계, 새 세션·창, 좌우·상하 분할, 이름 변경, layout 선택, pane·window·session 종료, 명령 전송 | 좌측 `tmux` 전체 작업면 |
| 제공사·사용량 | CLI 감지, Claude·Codex·Gemini·Grok 상태, 한도·토큰, 새로고침 | 전역 상태 팝오버, 상세 사용량 탭 |
| 설정 | 한국어·영어·중국어, 라이트·다크, AI 표시, 버전 비교, 업데이트 확인·다운로드·설치·릴리스 노트 | 좌측 `설정` 화면 |
| 도움·품질 | 10분 시작 가이드, 빠른 이동, 단축키, 오류 재연결·복사, 로딩·빈 상태·파괴적 확인 | 상단 도움 메뉴, 전역 모달·토스트 |
| 모바일 | 핵심 탐색, 프로젝트 선택, 고급 기능 더보기, 상세 drawer, 수평 넘침 방지 | 하단 4개 핵심 탭 + `더보기` sheet |

## 비배치 원칙

- 제공사 한도, 설정, 업데이트, 필터는 인과선 위에 상시 카드로 놓지 않는다.
- 상세 대화와 PowerShell 출력은 같은 패널에 섞지 않는다.
- 터미널과 tmux는 축소 카드로 흉내 내지 않고 실제 작업면 크기를 빌린다.
- 완료 기록은 삭제하지 않되 현재 실행보다 낮은 대비로 표시한다.

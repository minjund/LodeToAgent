# 스케치 005: Project-first Workspace

## 디자인 질문

왼쪽에 프로젝트가 항상 보이고, 프로젝트를 누르면 현재 상태와 지금 하는 일, 진행 중인 작업, 지난 작업, 새 세션 추가가 한 화면에서 자연스럽게 연결되는가?

## 보는 방법

`.planning/sketches/005-project-first-workspace/index.html`을 브라우저에서 연다.

## 변형

- **A: 현재 상태 우선** — 지금 하는 일을 가장 크게 보여주고 진행 중인 작업과 지난 작업을 아래에서 나란히 확인한다.
- **B: 시간 흐름** — 현재 작업부터 과거 완료 기록까지 하나의 프로젝트 타임라인으로 보여준다.
- **C: 세션 보드** — 진행 중, 확인 필요, 지난 작업을 세 개의 세션 열로 나눠 운영 상태를 비교한다.

## 상호작용

- 왼쪽 프로젝트를 누르면 프로젝트명, 경로, 현재 상태, 지금 하는 일이 바뀐다.
- `세션 추가`는 새 작업과 AI를 선택하는 모달을 연다.
- 진행 중인 작업이나 지난 작업을 누르면 대화·진행 과정·사용량 드로어가 열린다.
- 프로젝트 검색, 세션 상세 탭, 메시지 전송, 상태 순환, 반응형 미리보기가 동작한다.

## 무엇을 찾아봐야 할 것

- 프로젝트 목록에서 이름과 한 줄 상태만으로 어디에 개입해야 하는지 알 수 있는가?
- 프로젝트를 연 뒤 첫 시선이 `지금 하는 일`로 가는가?
- 진행 중인 작업과 지난 작업이 서로 섞이지 않으면서도 한 프로젝트의 연속된 기록으로 느껴지는가?
- 새 세션 추가가 프로젝트 문맥을 잃지 않고 시작되는가?

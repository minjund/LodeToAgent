# 스케치 009: Inline PTY Toggle

## 디자인 질문

현재 LoadToAgent의 사이드바, AI 사용량, 프로젝트 묶음, 작업 흐름과 버튼 위치를 전혀 재설계하지 않고 다음 두 동작만 바꿀 수 있는가?

1. AI 클릭: 오른쪽 팝업 대신 클릭한 AI 에이전트 행의 바로 다음 줄에 동일 PTY를 토글한다. PTY 다음에 지난 기록이 이어지며, 기록 영역 위·아래에 PTY를 붙이지 않는다.
2. 작업 진행 화면 보기: 기존 팝업의 요약·진행 과정·사용량을 상세 화면에서 보여준다. 요약에는 현재 작업의 총 토큰·입력·출력을 바로 노출하고, 사용량 탭에는 컨텍스트와 캐시 세부 항목을 제공한다.

## 보는 방법

`.planning/sketches/009-inline-pty-toggle/index.html`을 브라우저에서 연다.

## 상태

- **PTY 닫힘** — 현재 화면 그대로이며 오른쪽 팝업도 표시하지 않는다.
- **PTY 열림** — 클릭한 AI 에이전트 행 바로 아래, 지난 기록보다 앞에서 작업 영역의 전체 폭으로 PTY가 열린다. 연결선과 선택 강조가 PTY의 소유 AI를 표시한다.
- **상세 화면** — 작업 진행 화면 보기 버튼으로 이동하며 요약·진행 과정·사용량을 제공한다. 요약에서도 현재 작업의 핵심 토큰량을 확인할 수 있다.

## 무엇을 찾아봐야 할 것

- 기존 화면에서 바뀐 부분이 PTY 위치와 상세 정보의 목적지뿐으로 보이는가?
- 같은 AI를 다시 누르면 PTY가 닫힌다는 사실이 자연스럽게 전달되는가?
- PTY가 지난 기록이 아니라 클릭한 AI 에이전트에 연결된 화면으로 이해되는가?
- `작업 진행 화면 보기`가 기존 팝업 상세 정보의 새 목적지로 이해되는가?
- 상단의 주간 AI 사용량과 현재 작업의 토큰량이 서로 다른 수치임이 명확한가?
